## 背景

G3 是「事件 → 因果圖 → 前瞻登記」這條軌道的每週掃描協議。
2026-08-14 首次執行產出四筆登記，事後審計**全部無效**——
入口節點都是既有節點的既有機制，輸出不含當週事件的任何資訊，不可證偽。
v3 因此把登記從「每週自動產生」改成「稀有且需人工核可」，有效樣本數歸零。

2026-08-24 的掃描把 `ST-RU-EXPORT-INFRA-DAMAGE → CH-GRAIN-SUPPLY` 列為
本週最高優先的 3-B（調參）候選：2026-08-17 烏軍打擊使 Novorossiysk 三座穀物碼頭
（NKHP、NZT、KSK）全部停擺，而該邊的 `mechanism` 寫的是「估佔俄穀物出口 15–20%」，
量級引錯了一個級距。

**查核時另外發現一件更嚴重的事**：`patch_grain.py`（2026-08-21 寫好，
明白寫著「本次只更正機制文字」）**從未在 vault 執行過**。
協議第 1 步的重建比對照樣 `EQUAL: True`——因為它比對的是「seed 與 nodes 一致」，
而 seed 本身沒被改過。**圖是自洽的，只是自洽在一個已知錯誤的數字上。**

## 決策

依協議第 8 節走完提案 → 凍結 → 核可 → 改圖 → 跑引擎的順序，
把該邊調為 `confidence` 0.70／`evidence` 已實現，並產出 **G3 的第一筆有效登記**；
同時把協議升到 v3.3，加一條「改完 grep 驗收」堵住上述無聲失敗。

## 考慮過但沒選的選項

| 選項 | 為什麼不選 |
|---|---|
| **`confidence` 給 0.60** | 受阻運能約當俄羅斯海運穀物出口的 47%（Novorossiysk 三碼頭 2,500 萬噸 ÷ 盆地 4,630 萬噸 × 盆地佔全國 88%），不是原先假設的兩成。0.60 仍在為一個已被推翻的量級留餘裕 |
| **`confidence` 給 0.80** | 0.75 是「有先例」的認識論上限。**停擺持續時間未知**，而圖只有一組時滯，無法表達「停三週」與「停三個月」的差別。給到上限之上等於假裝那個變數不存在 |
| **`evidence` 只升到 `有先例`（上限 0.75）** | 與事實不符。這件事不是「有先例」，是**正在發生**且可定日期。用錯誤的證據等級來表達保守，會讓認識論上限這個機制本身失去意義——保守應該由 `confidence` 承擔 |
| **順便調 `lag_months`** | 本週沒有任何機制事實涉及時間結構。下界 0（裝載即刻停止）與上界 9（供給效果持續期）都未被新事實觸及。**能不改就不改**——每多改一個參數，事後就多一個無法歸因的自由度 |
| **先跑一次引擎看結果再定參數** | 協議第 8 節明文禁止。步驟 1–2 先於步驟 4 是這整個流程唯一真正的保護；先看輸出再定參數，連前瞻的形式都不剩 |
| **修改 `patch_grain.py` 或 8/21 的提案，讓紀錄看起來一致** | 修改凍結紀錄來掩蓋問題，比問題本身嚴重。改為在新提案的第 0 節公開這個查核發現 |

## 依據的假設

1. **量級推算成立**：2,500 萬噸 ÷ 4,630 萬噸 × 88% ≈ 47%。
   來源是 SovEcon 與俄羅斯穀物聯盟——**產業權威，不是官方統計**。
   **未升級到 USDA／IGC，這個假設可能過期。**
2. **共用作業已被觀察證實**：油品與穀物碼頭同時停擺（F1–F3），
   原 `breaks_if`「兩者互不影響」已被證偽。
3. **停擺會持續到足以影響供給的長度**——**這是最脆弱的假設**。
   Tuapse 仍在運作，2026 年俄羅斯收成約 1.4 億噸（強收成），供給端起始水位高。
   新的 `breaks_if` 就是寫這個。
4. 圖的其餘 139 條邊維持原狀，本次判斷仍然建立在一張**絕大多數邊未經實證檢驗**的圖上。

## 判準：什麼情況下要推翻這個決策

**登記本身的判準**（事先寫死，見 `G3-登記-2026-08-25.md`）：

- 立即層 **2026-11-17**、短期層 **2027-08-17**、中期層 **2029-08-17**
- 對照基準＝事件前一個月（2026-07-17～08-17）的平均水準
- 只計 `type: outcome` 且 |淨信心| ≥ 0.10 的判斷；**未覆蓋計為錯誤，不是棄權**

**這次調參要被推翻的情況**：

- `breaks_if` 觸發——Tuapse／波羅的海／陸路在數週內補足受阻運能，或碼頭快速復工
- USDA／IGC 的官方統計顯示 Novorossiysk 三碼頭的佔比顯著低於 40%
  → 量級假設垮掉，`confidence` 應退回

**整條 G3 軌道的判準**（未變）：3 筆獨立登記、來自 ≥3 個不同週次之後才做整體評估；
錯誤率 > 50% 應停止使用圖譜做任何推導。**目前 1／3，單一登記只記錄、不解讀。**
