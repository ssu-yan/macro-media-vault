# 2026-08-13 建立媒體結構沙盤

## 背景

Wendy 問「傳統媒體的改變會如何影響經濟走向，進而預測市場走向」。
這是 Macro economics project 的核心命題。初次討論後，決定不停留在對話，
而是建立一個結構化、可迭代、可證偽的 vault。

## 決策

建立 `macro-media-vault`（Obsidian，桌面，已納入 Git）。
採**條件式推導**架構而非預測架構：每個節點列出 2–3 個分岔與機率，
並明確寫出上游分岔如何決定下游分岔。

核心立場：**媒體結構改變影響的是市場的二階量（波動、離散度、輪動速度、
情緒與基本面的耦合），不是方向。** 推導到 S9 為止，不延伸到方向。

## 考慮過但沒選的選項

**選項 A：直接給市場方向的判斷。**
不選。從媒體結構到價格方向中間隔太多層，每一層都會稀釋訊號。給方向判斷會顯得
有用，但那是假的精確度。這類推論的失敗方式通常不是「方向錯了」，而是
「即使方向對，時間尺度也差到讓你先破產」。

**選項 B：以廣告產業為主軸。**
不選。2026 全球廣告仍成長 +5~9.8%，是重分配不是縮水。「傳統媒體崩＝經濟差」
是錯誤推論。這條線刻意在主圖畫成虛線並在 S1 明確標示為「比大家以為的不重要」。

**選項 C：單頁長文。**
不選。Wendy 明確要求看到節點間的分岔傳導，單頁無法表達，也不利後續逐節點深挖。

**選項 D：把 S8（資本支出）當作主要結論。**
不選，但保留節點並**明確標示為最弱一環**。它是唯一能推到「方向」的節點，
誘惑很大，但從 S0 到 S8 隔了七層，且 2026 當下 AI 資本支出的力量遠大於
任何不確定性效應。誠實標示弱點比讓它拖累整張圖的可信度好。

## 依據的假設

| 假設 | 可能過期的方式 |
|---|---|
| 世代效應 > 生命週期效應 | 若年輕世代中年後回歸傳統管道 → V4 可檢驗 |
| 信念離散度確實在上升 | 目前只有代理變數，無直接測量 → V2 |
| 情緒指標的預測力正在衰退 | **V1 直接檢驗，尚未執行** |
| AI 分發會走向集中或碎片 | L4 是雙穩態，尚未明朗，可能還要 3–5 年 |
| 媒體是情緒脫鉤的原因之一 | 通膨、住房、政治極化都是競爭性解釋，識別很弱 |

## 判準：什麼情況下要推翻

**主判準（已寫進 [[L5-長期市場均衡]] 與 [[V1-結果]]）：**
若 V1 跑出來，消費者信心對後續消費的增量 R² **沒有**逐段下降
→ 整張沙盤可信度大幅下修。

這是刻意的自我檢驗設計：把最容易驗證的環節當作整條鏈的代表性樣本。
如果最好驗的那一段都不成立，沒有理由相信更難驗的那幾段。

**次判準：**
- 若 [[L4-集中化vs碎片化]] 在 3 年內明確倒向 L4-A，則所有基於「離散度上升」的
  短期結論需要反向重寫
- 若 V2 的分政黨信心差距沒有擴大，則媒體效應的識別基礎瓦解

## 附註

**技術限制（會重複遇到）：** 這個 vault 透過雲端連線操作時沒有刪除權限，
git 每次操作都會殘留 `.lock` 與 `tmp_obj_*` 檔案，需手動搬走，否則
下次 `git add` 會因 `index.lock` 存在而失敗。長期做版控操作建議在本機執行。

**執行環境限制：** 雲端容器的網路白名單擋掉 `fred.stlouisfed.org`，
總體經濟資料無法自動取得，需手動下載。這會影響所有後續的量化驗證任務。

**推演過程中冒出、但不在原問題範圍內的三個發現：**
1. L4 是真正的雙穩態，兩個結局需要**相反**的部位結構，無法兩邊押注
2. 若走 L4-A（AI 再集中化），央行溝通效力可能**反而回升**——說服 2–3 個模型
   比說服一億個分裂的使用者容易。推論：未來央行可能出現「模型關係」職能
3. 情境 C（敘事失控）的引信是**官方統計機構的公信力**，這個引信在很前面、
   可觀察、且追蹤成本極低。這可能是整張沙盤最實用的單一產出
