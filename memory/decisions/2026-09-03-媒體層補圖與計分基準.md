# 2026-09-03　媒體層補圖落地 ＋ 計分加天真基準

> 依 `sop/after-action-template.md`。同日兩件事：協議 v3.7→v3.8→v3.9，圖 81→85 節點。

## 背景

Wendy 問「你會如何繼續擴展這個預測模型」。我的回答是**不要往更多節點擴**——
瓶頸不是覆蓋率：140 條邊、1 筆有效登記、回饋 3 個月到 3 年，
圖的成長速度與驗證速度差了兩三個數量級，補圖只會把差距拉開。

我提了三件該做的事與一個更基本的洞。Wendy 挑了其中兩件：
**加天真基準**、**補上這個 Project 真正的主題**。

查核後發現的事實比預期嚴重：**81 個節點裡「媒體」領域只有 1 個**（`ST-INFO-WAR`），
它唯一的出邊指向 `S3-信念離散度上升`，而那是**圖外終點**。
沙盤層的 S3／S4／L4 全是有入邊、沒有出邊的死端。
**本 Project 的命題（媒體結構 → 經濟 → 市場）在圖裡只有前半段。**

## 決策

1. **計分加天真基準**（協議 v3.8）：每筆登記凍結時同時記錄一個基準判斷，
   計分時兩者用相同規則各算一次錯誤率並列。
2. **媒體層第一批補圖**（協議 v3.9）：新增 4 節點 6 邊，81→85 節點、140→146 邊。
   讓媒體層第一次能夠傳導。

## 考慮過但沒選的選項

| 選項 | 為什麼不選 |
|---|---|
| **繼續補更多領域節點** | 瓶頸不是覆蓋率。每加一個節點，未經檢驗的表面積就多一塊，而驗證速率不變 |
| **先補平台監管介入**（08-31 掃描的最高優先 R7） | 媒體層還是死端的時候，監管節點只能接到既有經濟節點，**繞過命題本身**。必須先讓媒體層能傳導 |
| **先補廣告／注意力景氣通道** | 資料最好取得，但它測的是「媒體產業的景氣」而非「媒體結構改變如何影響經濟」——離命題最遠 |
| **訂一個「圖要贏基準幾個百分點」的門檻** | 3 筆登記只有數十筆判斷，任何百分比差距都在雜訊裡。訂了會**假裝有精度**。改為只當必要條件：沒贏基準就不得宣稱有前瞻價值 |
| **回頭幫 08-25 那筆登記補基準欄** | 事後補填等於沒有基準（可以挑一個讓圖好看的算法），且違反不改凍結紀錄。改為單獨列出並註明「無基準」 |
| **畫 `S3 → 報酬` 的邊** | 見下方「依據的假設」。文獻對符號沒有共識 |
| **升 `S7` 的認識論狀態以解除 0.45 上限** | 那個狀態記的是「**本 vault** 檢驗過沒有」，不是世界上有沒有人檢驗過。外部文獻再強也不能拿來升它 |
| **新節點改用 ASCII id** | Wendy 明確指示：不做會讓沙盤層與圖譜層命名脫節的事。故沿用 `S3-`／`S7-` 與 `epistemic.yaml` 的鍵一致，代價是檔名含中文（已驗證 `export_snapshot.py` 不會跳過） |

## 依據的假設

1. **「意見分歧 → 成交量／波動」的方向是穩定的。** 來源：Carlin, Longstaff & Matoba（JFE 2014）。
   ⚠️ **但那是 MBS 市場，不是股票市場**，外推是我做的。而且 S3 的兩條出邊引用**同一篇論文**——
   讀的人很容易把兩條邊當成兩份獨立證據，它們不是。
2. **「報紙文本建構的政策不確定性 → 投資下降、波動上升」的方向是穩定的。**
   兩個獨立來源同方向：BBD（QJE 2016）與 Caldara et al.（Fed IFDP 1256, 2019）。
   ⚠️ 兩者的衝擊大小定義不同，**只採方向、不採量級**；且**都是美國口徑**。
3. **「意見分歧 → 報酬」的符號沒有共識**——這是**不畫**那條邊的依據，
   而它本身是一個會過期的假設。2026-09-03 的盤點：
   - 負向：Diether-Malloy-Scherbina（JF 2002）
   - 正向：Carlin-Longstaff-Matoba（JFE 2014）；Kim & Na（JEmpFin 2016）在**同一資料集**
     換一個離散度定義就翻號
   - 取決於狀態：Atmaz & Basak（JF 2018）樂觀時負、悲觀時正
   - 是別的東西在驅動：Johnson（槓桿）、Avramov et al.（信評）、Min-Qiu-Roh（未來獲利）、
     Hwang-Wong-Yi（分析師自我審查）——**四個解釋彼此互斥，但共同顯示係數對控制變數極不穩健**
   - 複製：Hou-Xue-Zhang（RFS 2020）在 NYSE 分界＋市值加權下，十分位多空報酬**全部落在零的
     一個標準誤之內**。**這個效果活在等權與微型股設定裡。**
   - 找不到任何一篇針對這條關係的量化 meta-analysis。
4. **天真基準（前 12 個月漂移方向）是一個公平的對照。** 它可能太弱（趨勢延續在多數
   總體序列上表現不差）也可能太強，這件事要等真的算過才知道。

## 判準：什麼情況下要推翻這個決策

**天真基準**
- 若第 2 筆之後的登記顯示**基準的錯誤率系統性地優於圖**，那不是基準訂錯，是圖沒有價值
- 若基準算法在實作時發現無法對某類 outcome 定義（例如沒有連續序列的政治事件節點），
  該處置要寫成規則，**不得逐案裁量**

**媒體補圖**
- `S3` 的兩條出邊：若控制成交量後波動與分歧的關係消失，或該關係只存在於單一資產類別 → E2 不成立
- `S7` 的兩條出邊：若控制 VIX 後關係消失、或控制利率與需求預期後投資對政策不確定性無反應 → 不成立
- **若日後出現針對「分歧 → 報酬」的量化 meta-analysis 且顯示符號有共識**，
  「不畫報酬邊」這個決定就該重新檢視

**整條 G3 軌道**（未變）：3 筆獨立登記、來自 ≥3 個不同週次才做整體評估。目前 1／3。
