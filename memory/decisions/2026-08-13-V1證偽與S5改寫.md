# 2026-08-13 V1 證偽 S5，改寫為校準漂移假說

## 背景

沙盤建立當天就跑了 V1（消費者信心對後續實質消費的預測力分段檢定）。
判準是**事先寫死**的：若增量 R² 沒有逐段下降，整張沙盤可信度大幅下修。

## 決策

**照判準辦，但把下修範圍講清楚，並用同一批資料換一個更好的主張。**

1. 承認 [[S5-情緒與支出脫鉤]] 原本的機制描述（「情緒指標失去預測力」）**證偽**
2. 追加 V1b（樣本外偏誤檢定），確認真正發生的是**水準校準漂移**
3. 改寫 S5，保留現象、換掉機制
4. 在 [[沙盤總覽]] 加修正橫幅，不隱藏這次的錯誤

## 結果摘要

- V1：增量 R² 三段為 0.129 / **0.000** / **0.124**（h=3）。**未下降**，最近一段最高
- 真實型態是**狀態相依**（波動期強、平靜期弱），不是單調衰退
- V1b：用 2019 年前關係外推，2021 年後 **86–100% 月份低估**實際消費，t 值 4.8–8.5

## 考慮過但沒選的選項

**選項 A：修改判準，主張「狀態相依也算一種失效」。**
不選。這正是判準要防的東西——跑完之後才決定怎樣算成功。如果允許這次通融，
之後每一次驗證都會變成事後合理化。

**選項 B：不追加 V1b，直接接受證偽並刪掉 S5。**
不選。因為「信心 49.5 而消費沒崩」這個現象是**真的**，眼睛看得到。
證偽的是機制描述，不是現象。刪掉整個節點會丟掉真實的觀察。

**選項 C：把 V1b 的完整模型結果（偏誤 +5.7~7.9pp）當主要證據。**
不選，雖然數字更漂亮。控制變數裡的聯邦資金利率在 2021 年後遠超訓練期範圍，
外推不可靠。用僅情緒模型（+1.5~2.3pp）當主要讀數，較小但可信。

## 依據的假設與它們的狀態

| 假設 | V1 之後 |
|---|---|
| 情緒指標失去預測力 | ❌ 證偽 |
| 情緒與支出存在脫鉤 | ✅ 確認，且比原本描述的更確定 |
| 脫鉤是媒體造成的 | ❓ **完全未辨識**。通膨水準效應、政治化回答同樣能解釋 |
| 骨架（S3 → S9）不依賴 S5 | ✅ 成立，核心結論不受影響 |

## 方法上學到的一件事（值得記住）

**跨期比較 R² 本身就有問題。** R² 被各期的變異數污染——當兩個變數都不太動的時候，
R² 本來就低。2013–2020 的「零」有相當程度只是因為那段時期太平靜。

更好的設計應該是比較**係數穩定性**或**樣本外預測誤差**，而不是 R²。
V1b 用的就是後者，所以它的結論比 V1 更站得住。

**這個錯誤是我在設計 V1 時沒想清楚的。** 下次設計驗證任務時要先問：
這個統計量會不會被我不感興趣的東西污染？
