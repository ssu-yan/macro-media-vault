## 這是什麼（以及不是什麼）

**是：一張條件式推理地圖。**
把「媒體結構改變會怎麼影響經濟與市場」拆成節點，每個節點列出可能的分岔，
並明確寫出上游倒向哪一邊、下游會被推向哪一邊。

**不是：預測模型。**
這個 vault **不宣稱**能預測市場方向、波動水準或估值。
它裡面的推導是**條件式的假說**，絕大多數**尚未經過實證檢驗**。

### 為什麼要講這麼白

建立當天跑的第一個驗證任務（V1）就**推翻了整條鏈上最直覺、最容易驗證的那個節點**
（[[S5-情緒與支出脫鉤]]）。47 年的資料顯示消費者信心的預測力完全沒有衰退。

一個推導了 27 支筆記的框架，目前的實證記錄是 **0 勝 1 敗**。

在這種記錄下繼續自稱「預測框架」是不誠實的。所以定位改成推理工具：
它整理問題的能力是真的，它的預測宣稱不是。

## 怎麼用它

| 用途 | 做法 |
|---|---|
| **事件定位** | 新聞發生時，查它落在哪個節點、會把哪些下游推向哪個分岔 |
| **假說管理** | 每個主張都標了認識論狀態（已證偽／未檢驗／難以檢驗），不會把假設當事實 |
| **決策留痕** | `memory/decisions/` 記錄「當初為什麼這樣決定」，包含被排除的選項 |
| **驗證方法庫** | `04-indicators/` 存的是「如果要驗證，方法長這樣」，不是待辦清單 |

**不要用它做：** 部位決策、方向判斷、任何需要預測力的用途。

## 節點命名規則

- `S#` 短期（1–3 年）／`L#` 長期（5–10 年）
- 每支節點四段：**狀態 / 分岔 / 觸發訊號 / 下游影響**
- 分岔標 A/B/C 與機率，並寫出它把哪個下游推向哪一個分岔
