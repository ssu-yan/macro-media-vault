# macro-media-vault

主題：**傳統媒體結構改變 → 經濟走向 → 市場走向**
建立日期：2026-08-13
定位：這是一個**沙盤推演型 vault**。核心不是收集資料，而是把因果鏈拆成節點，明確寫出每個節點「往哪邊倒」會怎麼改變下游。

---

## 核心命題

> 傳統媒體衰退對經濟的影響，不在廣告產業本身，而在**「社會如何形成共識」的機制被拆掉了**。
> 這個機制改變首先影響的是市場的**二階量**（波動、離散度、輪動速度、情緒與基本面的脫鉤），而非方向。

完整論證見 [[沙盤總覽]]。

## 資料夾地圖

| 資料夾 | 內容 | 何時讀 |
|---|---|---|
| `00-index/` | 沙盤總覽（主圖）、節點索引 | **每次開始工作先讀這個** |
| `01-nodes-short/` | 短期節點（1–3 年，可驗證） | 要推導可交易結論時 |
| `02-nodes-long/` | 長期節點（5–10 年，結構性） | 要談體制轉變時 |
| `03-scenarios/` | 三條完整情境劇本（走完整條鏈） | 要看「如果 A 成立，最終長什麼樣」 |
| `04-indicators/` | 可追蹤指標與驗證方法 | 要把推論變成可檢驗命題時 |
| `05-sources/` | 證據基礎與引用 | 要查數字出處時 |
| `99-inbox/` | 未整理的想法、待驗證問題 | 隨手丟 |

---

## 節點命名規則

- `S#` = 短期節點（Short-term，1–3 年）
- `L#` = 長期節點（Long-term，5–10 年）
- 每支節點筆記固定四段：**狀態 / 分岔 / 觸發訊號 / 下游影響**
- 分岔用 `分岔 A / B / C` 標示，並在「下游影響」直接寫出它把哪個下游節點推向哪一個分岔

---

## 使用方式

1. 讀 [[沙盤總覽]] 看整張圖
2. 挑一個節點，讀它的四段結構
3. 看「觸發訊號」→ 去 [[追蹤指標清單]] 找對應的可觀察數據
4. 有新證據 → 更新節點的「狀態」欄，並在 `05-sources/` 補來源
5. 推論成形 → 寫成 after-action 存進 `03-scenarios/`
