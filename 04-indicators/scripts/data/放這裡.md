# 把 FRED 的 CSV 放進這個資料夾

到下面五個頁面，各按右上角 **Download → CSV**，檔名不用改，直接丟進這個資料夾：

| 序列 | 內容 | 連結 |
|---|---|---|
| `UMCSENT` | 密西根消費者信心指數 | https://fred.stlouisfed.org/series/UMCSENT |
| `PCE` | 名目個人消費支出（1959 起）| https://fred.stlouisfed.org/series/PCE |
| `PCEPI` | PCE 物價指數（1959 起）| https://fred.stlouisfed.org/series/PCEPI |

> ⚠️ **不要用 PCEC96。** FRED 的 PCEC96（實質個人消費支出）序列只從 2007 年開始，
> 太短，會讓 2000–2012 那一段實際上變成 2008–2012（全部落在金融海嘯期間）。
> 改用 `PCE ÷ PCEPI` 自行實質化，可以回推到 1959 年。
| `UNRATE` | 失業率 | https://fred.stlouisfed.org/series/UNRATE |
| `FEDFUNDS` | 聯邦資金利率 | https://fred.stlouisfed.org/series/FEDFUNDS |
| `DSPIC96` | 實質可支配所得 | https://fred.stlouisfed.org/series/DSPIC96 |

放好後執行：

```
cd 04-indicators/scripts
python3 V1_backtest.py
```

只需要 `pandas` 和 `numpy`。OLS 與 Newey-West 標準誤都在腳本裡自己算，不需要 statsmodels。

> 這些 CSV 已被 .gitignore 排除，不會進版控（原始資料應該從來源重新下載，不該塞進 repo）。
