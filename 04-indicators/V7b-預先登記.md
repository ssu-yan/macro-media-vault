## 0. 先講清楚這份檢定**能**與**不能**做到什麼

V7 的 H3 沒過，而它沒過的方式是：**前兩段幾乎持平、後兩段掉到三分之一**——
看起來像 **2016 年前後的一次水準位移**，不是逐段下滑。

**但那個「2016」是從 V7 的資料裡看出來的。**
拿資料建議的日期回去檢定同一份資料，是循環論證。

**所以本檢定的處置表刻意設計成「只能維持或下修，不能上修」。**

| V7b 能做的 | V7b 不能做的 |
|---|---|
| **把水準位移這個說法排除掉**（若統計量不顯著） | **證實它** |
| 顯示斷點其實落在金融海嘯／COVID／通膨衝擊上（那會**反對**媒體故事） | 把 `S6` 從「證據混雜」升到「有支持」 |
| 顯示市場端在同一時點也斷掉（那代表**不是家計通道特有**） | |

**要真正上修 `S6`，需要的是樣本外證據**——例如在**另一個經濟體**
（歐元區的家計通膨預期 vs 市場隱含通膨）重跑同一套檢定。
那會是 V7c，不在本案範圍。

## 2. 三個檢定與判準（**寫死**）

### B1：資料驅動的斷點檢定（sup-Wald ＋ 移動區塊 bootstrap）

對「共動 ~ 常數 ＋ 時間趨勢」這個模型，在所有候選斷點上算 Chow / Wald 統計量，
取最大值（sup-Wald），並記錄使它最大的日期。

- **候選範圍**：兩端各修剪 15%（標準作法，避免端點的偽斷點）
- **虛無分布**：**移動區塊 bootstrap**，區塊長度 **24 個月**，重抽 **2000 次**
- **為什麼用 bootstrap 而不是查表**：滾動視窗高度重疊，序列相關極強，
  查表用的臨界值在這裡**無效**。bootstrap 自己把相關結構抽進去。
- **判準**：bootstrap p 值 **< 0.05** → 「有斷點」

⚠️ **區塊長度 24 是妥協。** 重疊視窗誘發的相依長度接近 60 個月，
但 n = 223 之下用 60 只剩約 4 個區塊，bootstrap 會失去意義。
**24 會低估相依、因此偏向於「找到斷點」——這個偏誤的方向對本檢定不利，要記住。**

### B2：斷點落在哪裡（**反證用，不作為支持**）

事先寫死三個**非媒體**的對照日期：

| 事件 | 日期 |
|---|---|
| 全球金融海嘯 | 2008-09 |
| COVID 衝擊 | 2020-03 |
| 通膨衝擊起點 | 2021-04 |

- **判準（反證）**：若 B1 估到的斷點**與上述任一日期相距 ≤ 12 個月**，
  則認定該斷點**更可能來自總體衝擊而非媒體結構**，**這對媒體故事是反證**。

⚠️ **本項刻意不設「落在媒體區間就算支持」的判準。**
因為 2016 這個日期是我從資料裡看到的，設那種判準等於自我實現。
**B2 只能扣分，不能加分。**

### B3：安慰劑（市場內部）

對 V7 的市場內部共動序列（Δ`T5YIFR` vs Δ`T10YIE`）跑**同一套** B1。

- **判準**：若市場內部**也**在 B1 估到的斷點 ±12 個月內出現顯著斷點，
  則該斷點**不是家計通道特有**，**這對 S6 的不對稱主張是反證**。

## 4. 這個檢定測不到什麼

1. **假說是從同一份資料生出來的。** 這是本案最根本的限制，bootstrap 修不了它。
2. **只有一個斷點。** 沒有檢定多重斷點（Bai-Perron 那類），若真實過程有兩個以上的
   結構變化，sup-Wald 會挑出最強的那一個並掩蓋其餘。
3. **斷點的日期估計本身有很大的不確定性**，尤其在重疊視窗的資料上。
   **不得把估到的月份當成精確日期來講故事。**
4. **共動不是傳導**、**`MICH` 是中位數不是離散度**——與 V7 相同的限制照舊成立。
