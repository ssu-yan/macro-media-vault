# 事件因果圖譜：規格與使用說明

目標：**輸入一個事件 → 定位節點 → 沿邊傳導 → 輸出可觀察結果的方向、時序、信心。**
涵蓋政治、經濟、戰爭、能源、糧食、AI、媒體。

第一版：俄烏戰爭（2022）完整範例，31 個節點。

---

## 為什麼這個系統一半的設計是在「抑制輸出」

這個 vault 今天才親眼看過一件事：**一個手寫的因果節點（[[S5-情緒與支出脫鉤]]），
在檢驗下死得乾乾淨淨。**

一張有幾百條邊的圖，就是幾百個未經檢驗的斷言。而且**圖越大越有說服力，
越難察覺哪裡是空的**。所以：

| 機制 | 作用 |
|---|---|
| **信心沿路徑相乘衰減** | 三跳各 0.8 只剩 0.51。防止「六跳漂亮故事」 |
| **同向多路徑取 max 不取 sum** | 多條路徑常共用底層機制，相加會系統性高估 |
| **反向邊是一等公民** | 每個節點都要列反向力量。只記推力的圖是確認偏誤製造機 |
| **按時間分層淨計** | 反向力量的時滯常比主推力長，混在一起會錯過「先漲後崩」 |
| **淨信心 < 0.10 標為方向不明** | 不硬給方向 |
| **找不到節點就報錯** | **最重要**：寧可說「圖裡沒有」，也不生成沒有記錄的因果鏈 |

## 用法

```bash
cd 10-graph/engine
python3 propagate.py 俄烏戰爭              # 傳導分析
python3 propagate.py --list                # 列出所有節點
python3 propagate.py 俄烏戰爭 --depth 3     # 限制跳數
python3 propagate.py 俄烏戰爭 --json        # 機器可讀輸出
```

只需要 `pyyaml`。

## 節點格式

每個節點是一個 `.md`，YAML frontmatter 存結構，正文存說明。

```yaml
---
id: ST-RU-GAS-CUT              # 唯一識別碼
label: 俄羅斯對歐天然氣供應削減      # 顯示名稱
type: state                    # event | state | channel | outcome
domain: 能源                    # 戰爭/政治/經濟/能源/糧食/市場/AI/媒體
status: 已發生                   # 已發生 | 進行中 | 已緩解 | 可觀察 | 假設
date: 2022-02-24               # 僅 event 需要
aliases: [北溪, 俄羅斯斷氣]        # 事件比對用
edges:
  - to: CH-ENERGY-SUPPLY       # 下游節點 id
    sign: 1                    # +1 推升 / -1 抑制
    lag_months: [0, 3]         # 時滯區間
    confidence: 0.95           # 這條邊單獨成立的機率 × 強度
    mechanism: "歐洲最大單一氣源退出"
    evidence: "已實現"            # 已實現 / 有先例 / 理論推導
    breaks_if: "管線恢復輸送"       # 什麼情況下這條邊不成立
---
```

### 四種節點型別

| 型別 | 意義 | 例 |
|---|---|---|
| `event` | 有日期的一次性事件，圖的入口 | 俄羅斯入侵烏克蘭 |
| `state` | 持續的狀態或條件 | 黑海航運封鎖、對俄制裁 |
| `channel` | 傳導機制，不直接可觀察 | 穀物供給衝擊、投入成本上升 |
| `outcome` | 可觀察／可交易的終點 | 小麥價格、ECB 利率、國防類股 |

### 三種證據等級

- **已實現** — 這條邊在真實世界已經發生過，可指出具體時間與數字
- **有先例** — 歷史上類似情境發生過，但本次未必重演
- **理論推導** — 只有機制論證，沒有實證。**這種邊的信心不該超過 0.5**

## 一個真實的輸出範例（俄烏戰爭）

```
── 立即（0–3 個月）
  ↑ 歐洲天然氣價格 (TTF)   推升  淨信心 0.77
      主路徑：入侵 → 俄對歐減供 → 歐洲能源供給衝擊 → TTF

── 短期（3–12 個月）
  ↓ 歐洲天然氣價格 (TTF)   抑制  淨信心 0.58
      主路徑：入侵 → 俄對歐減供 → LNG 替代與接收站擴建 → TTF
```

**同一個節點在兩個時間層方向相反**，而這正是 2022–2023 年實際發生的事：
氣價 2022 年 8 月逼近 340 歐元，2023 年回落至戰前水準附近。

如果沒有按時間分層，引擎會把它們相抵成「小幅推升 +0.19」，
完全錯過真實型態。**這個修正是在第一次試跑看到錯誤輸出後才加上的。**

## 已知的結構性缺陷（先寫下來，不要等出錯才承認）

1. **沒有處理地區異質性。** 同一條邊在美國與新興市場的強度可能差三倍以上。
   糧價→CPI 就是最明顯的例子。
2. **沒有處理事件規模。** 「戰爭」不是二元的。同樣是衝突，交戰方在關鍵
   商品供應鏈的份額決定一切。目前的邊隱含了 2022 年俄烏的特定規模。
3. **信心值是判斷，不是估計。** 沒有任何一條邊的 confidence 是從資料估出來的。
   它們是我依證據等級給的主觀數字。
4. **反射性未處理。** 市場預期會提前反映，實際價格路徑可能與機制路徑不同步。
5. **沒有處理節點間的相關性。** max 而非 sum 是粗糙的補救，不是正解。

## 怎麼擴充

**加一個事件：** 在 `nodes/` 新增 `.md`，或改 `engine/seed_ruua.py` 後重跑。
新領域建議另開種子腳本（如 `seed_ai.py`），維持「腳本是真實來源」的規則。

**加一條邊：** 加在**上游**節點的 `edges:` 裡。同時務必補上該節點的
「反向力量與已知限制」——**沒有反向力量的節點是可疑的**。

**id 命名慣例：** `EV-` 事件、`ST-` 狀態、`CH-` 通道、`OUT-` 結果。

## 與媒體結構沙盤的關係

本圖與 [[沙盤總覽]] 是同一個 vault 裡的兩層：

- **沙盤**是單一主題（媒體結構）的深度推導，帶認識論狀態表
- **圖譜**是跨領域的廣度網路，帶傳導引擎

兩者已經接起來了：`ST-INFO-WAR`（資訊戰與敘事分裂）指向 [[S3-信念離散度上升]]。
但那條邊的信心刻意只給 0.45，而且註記了：**S3 本身尚未被檢驗，
它的鄰居 S5 已經被證偽，在 V6 跑完之前不該把重量放在這條邊上。**

這就是圖譜該有的樣子——**它必須知道自己哪裡是空的。**
