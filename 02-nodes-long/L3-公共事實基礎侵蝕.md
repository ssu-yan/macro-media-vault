# L3 公共事實基礎侵蝕

上游：[[L1-AI成為主要新聞介面]] ｜ 下游：[[L4-集中化vs碎片化]]（推向 L4-B）

## 狀態

經濟學裡有一個常被忽略的前提：市場運作需要 **common knowledge**——不只是「我知道 X」，而是「我知道你也知道 X，你也知道我知道你知道」。價格發現、契約、貨幣、乃至於預期管理，全都建立在這層之上。

傳統媒體最重要的經濟功能，就是**廉價地製造 common knowledge**。頭版新聞的價值不在於它告訴你什麼，而在於它讓你知道別人也看到了。

這個功能正在消失，而且**沒有替代品**。演算法分發生產的是 private knowledge——你知道 X，但不知道別人是否知道 X。

## 分岔

- **分岔 A：新的共識層出現**（約 30%）— 可能來自 AI（若走 L4-A，2–3 個模型輸出高度一致，反而成為新的 common knowledge 層）、或制度化的公共資料基礎設施。
- **分岔 B：持續侵蝕**（主線，約 50%）— 沒有替代品，社會逐漸適應在較少共同事實的狀態下運作。交易成本上升，但沒有崩潰。
- **分岔 C：關鍵領域崩解**（約 20%）— 侵蝕蔓延到**官方統計數據**本身。CPI、就業數據變成有爭議的政治文本。

**分岔 C 是整張沙盤裡最嚴重的尾部風險。** 如果連「失業率是多少」都沒有共識，那麼：
- 契約中的指數化條款（通膨連動債、薪資調整）失去公信基礎
- 央行的通膨目標制失去錨
- 所有宏觀分析的共同語言消失

這不是漸進退化，是**相變**。機率不高，但影響極大，值得單獨追蹤。

## 觸發訊號

- 官方統計機構受到的公開質疑事件頻率與層級
- 統計機構的預算、人事獨立性、發布時程是否受政治干預
- 民調中「對政府統計數據的信任」分項
- 是否出現有規模的**替代性私人統計**（如私部門通膨指數取得制度性地位）——這是分岔 C 正在發生的徵兆

## 下游影響

L3 幾乎單向推 [[L4-集中化vs碎片化]] 的 **L4-B**，並進而推向 L5-B（高波動體制）。

**但注意 L1 的反向力量：** AI 若走向低個人化、高一致性，它可以**重建** common knowledge，而且比傳統媒體更徹底——因為它是全球性的、即時的、且只有 2–3 個來源。L3 與 L4-A 是直接對抗的兩股力量，這是長期沙盤的核心張力。
