# L5 長期市場均衡

上游：[[L4-集中化vs碎片化]] ｜ 下游：無（終點）

## L5-A 低波動 / 高系統性風險（若走 L4-A）

**表面特徵：**
- 波動回落至歷史常態或更低
- 相關性上升、離散度下降 → 主動管理 alpha 空間縮小
- 風險溢價壓縮 → 估值倍數擴張
- 政策傳導效率回升（央行只需管理少數模型）

**真實風險：**
- 錯誤是**系統性**的，且沒有異議者當煞車
- 尾部事件**罕見但極端**——長期低波動累積槓桿，然後一次性釋放
- 這在形態上類似 2004–2007：低波動、高槓桿、共識性的錯誤定價

**這裡有個很不舒服的推論：** L5-A 的市場**看起來**比 L5-B 健康得多——低波動、高估值、政策有效。但它的脆弱性更大，只是脆弱性被隱藏了。**用波動當風險代理，在 L5-A 世界裡會系統性誤導。**

## L5-B 高波動 / 分散風險（若走 L4-B）

**表面特徵：**
- 波動基準線結構性抬高
- 離散度高、相關性低 → 主動選股 alpha 空間擴大
- 風險溢價結構性上調一級 → 估值倍數壓縮
- 政策傳導變鈍、時滯拉長

**真實風險：**
- 持續的高摩擦與高交易成本
- 中型危機更頻繁，但每次都不致命
- 長期資本形成受抑（若 [[S8-企業資本支出遞延]] 的效果為真）

## 對照表

| 維度 | L5-A | L5-B |
|---|---|---|
| 波動水準 | 低 | 高 |
| 尾部型態 | 罕見、極端 | 頻繁、中等 |
| 相關性 | 高 | 低 |
| 主動 alpha | 縮小 | 擴大 |
| 估值倍數 | 擴張 | 壓縮 |
| 政策有效性 | 高 | 低 |
| **真正的風險** | **隱藏、系統性** | **可見、分散** |

## 兩者共同的含意

不論走哪條，有兩件事都成立：

1. **用歷史波動校準的風險模型會失效。** L5-A 因為低估尾部，L5-B 因為基準線改變。兩邊都需要重新校準，只是方向不同。
2. **「情緒指標作為領先指標」的傳統會削弱。** 見 [[S5-情緒與支出脫鉤]]。

## 現在該做什麼

在 L4 分岔明朗前（可能還要 3–5 年），合理的做法不是押注結局，而是：

- 建立 [[L4-集中化vs碎片化]] 那四個關鍵變數的追蹤機制
- 在 [[S9-市場二階量改變]] 的結論裡，只執行信心度中高的兩條（選股 alpha、風控假設厚尾）
- 把 [[追蹤指標清單]] 的 V1 驗證任務跑完，確認「情緒指標失效」這個最可檢驗的環節是否真的成立

**如果 V1 的結果是「沒有失效」，那麼整張沙盤的可信度要大幅下修。** 這是設計上的自我檢驗機制——最容易驗證的環節同時也是整條鏈的代表性樣本。
