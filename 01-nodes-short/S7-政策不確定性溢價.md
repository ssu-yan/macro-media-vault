# S7 政策不確定性溢價

上游：[[S5-情緒與支出脫鉤]] [[S6-央行溝通失效]] ｜ 下游：[[S8-企業資本支出遞延]] [[S9-市場二階量改變]]

## 狀態

媒體碎片化 → 政治極化 → 政策路徑更難預測 → 不確定性溢價上升。這條鏈的每一環都有文獻支持，但**加總的效果量級不確定**。

機制上有兩層：
1. **選舉結果的變異數上升**（民調失準率提高、極端候選人可行性上升）
2. **同一執政者的政策一致性下降**（因為政治壓力來自更分裂、更即時的輿論回饋）

第二層被低估。碎片化媒體讓政治人物面對的是**高頻、分裂、極端化**的輿論訊號，這鼓勵短期反應式決策而非長期承諾。對經濟而言，**政策的不可承諾性**比政策的方向更傷。

## 分岔

- **分岔 A：制度緩衝有效**（約 30%）— 獨立機構、憲政限制、官僚體系吸收波動，實際政策比言論穩定得多。過去二十年這個緩衝一直有效。
- **分岔 B：溢價緩步上升**（主線，約 45%）— EPU 指數的基準水位逐級抬高。
- **分岔 C：制度緩衝失效**（約 25%）— 獨立機構本身被政治化（央行獨立性、統計機構公信力），此時不確定性溢價會**跳升**而非緩升。

**分岔 C 的引信要特別盯：** 官方統計機構的公信力受質疑，是這條鏈最危險的一環。如果連 CPI、就業數據本身都變成有爭議的政治文本，那麼整個宏觀分析的基礎——**大家對「數字是什麼」有共識**——就沒了。這不是漸進退化，是相變。

## 觸發訊號

- Economic Policy Uncertainty Index（Baker-Bloom-Davis）的滾動 3 年均值
- 選舉民調誤差的歷史趨勢
- **對官方統計機構的公開質疑事件**（分岔 C 的引信）
- 主要經濟體政黨輪替後的政策逆轉比例

## 下游影響

| 若走 | S8 資本支出 | S9 風險溢價 |
|---|---|---|
| 分岔 A | 無顯著影響 | 無 |
| **分岔 B** | **長天期投資溫和遞延** | **股權風險溢價 +25~50bp 量級** |
| 分岔 C | 顯著遞延 | 跳升，且長天期資產重估 |

**期限結構的含意：** 不確定性溢價上升對**長天期現金流**的傷害遠大於短天期。這意味著在分岔 B/C 下，成長股（現金流在遠期）相對價值股的估值優勢會被結構性侵蝕——與利率無關，純粹來自折現的不確定性成分。這是一個可以直接觀察的預測：**成長／價值的相對估值應該與 EPU 指數呈負相關，且這個關係在近十年應該增強。**
